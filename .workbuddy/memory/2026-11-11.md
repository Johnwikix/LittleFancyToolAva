# 2026-11-11

## 升级 .NET 11 并移除 global.json

- 全量 TFM 升级 `net11.0` / `net11.0-windows10.0.19041.0`；删除根目录 `global.json`（原固定 10.0.100，本机缺失导致 `dotnet` 退出码 155），SDK 现解析为 11.0.100。构建可重复性改由 CI 显式安装 >= 11.0.100 保证。
- **`PublishWithSatoriGC` 必须随主框架大版本同步升级**：`10.0.13-satori.38707290103.1` → `11.0.0-satori.42242472725.2`（SDK 解析的 Runtime/AotSdk 包为 `11.0.0-satori.42242472725.1`）。只改 TFM 会让 GC 运行时包与 net11.0 不匹配。NuSpec 仍为 MIT。
- .NET 11 新增 NU1510：`Microsoft.Extensions.Logging.Abstractions` 由框架自动提供，移除 Core 的显式 PackageReference 后恢复 0 警告。
- 重要修复：GUI / CLI 的 Core `ProjectReference` 需 `SkipGetTargetFrameworkProperties="true"` + `SetTargetFramework="TargetFramework=$(TargetFramework)"`。SDK 在 `GetTargetFrameworks` 协商阶段用 `RemoveProperties` 移除 `RuntimeIdentifier`（`Microsoft.Common.CurrentVersion.targets:1867/1883`），配合 `SetPlatform` 会让 Core 误判 Windows TFM，Linux 交叉构建必失败。这是 2026-11-03 `SetPlatform` 修复遗留的传递缺口。
- 验证：GUI Debug / CLI Debug / 7 个烟测工程 / Linux 交叉 Release 全 0 错误；NativeAOT Release 发布成功（99 MB），限时启动 15s 未复现 ADR 0007 的 .NET 11 RC XAML 缺失；CLI 自包含 `--help` 退出码 0。未验证 MSIX / `.deb` / 安装包 / Linux 真机 / GPU 推理。产物在 `.qa/net11-aot-2026-11-11/`。
- 文档：新增 `FancyTool/docs/adr/0023-net11-upgrade-and-unpinned-sdk.md`；`changelogs.md` 追加；ADR 0004 / 0007 文首加取代说明；AGENTS.md 与 README 双语同步（历史实测报告旧路径保留不改）。
